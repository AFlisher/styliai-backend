Versioning

Each document carries its own semantic version and effective date in its header block.

  • PATCH — typographical or formatting corrections that do not change meaning.
  • MINOR — clarifications, or new disclosures that do not reduce user rights.
  • MAJOR — any change that alters what is collected, who it is shared with, or what a user agrees to. A MAJOR change requires in-app notice before it takes effect.

The documents are versioned in git alongside the code they describe, so a change to the data flows and the change to the text that describes them land in the same history.
